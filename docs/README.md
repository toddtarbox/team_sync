## 📝 Documentation Guidelines

When adding new documentation:

1. **Essential docs** stay in the root `docs/` folder:
   - Architecture overviews
   - Setup/configuration guides
   - Feature documentation
   - Quick start guides
   - Testing guides

2. **Archive** detailed implementation notes to `archive/`:
   - Bug fix details
   - Step-by-step implementation notes
   - Historical troubleshooting guides
   - One-time migration notes

3. Use clear, descriptive filenames
4. Include a brief summary at the top of each document
5. Keep documentation up-to-date with code changes
