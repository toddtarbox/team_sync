# Quick Start Guide: Player Self-Editing

## For Coaches: Setting Up Player PINs

### Step 1: Navigate to Players Page
1. Open your team/season
2. Click on "Players" in the navigation

### Step 2: Edit or Create a Player
- **For Existing Player**: Click on a player card
- **For New Player**: Click the "+" button to add new player

### Step 3: Set the PIN
1. Scroll down to find the "Player Edit PIN (4 digits)" field
2. Enter a 4-digit number (e.g., 1234, 5678, etc.)
3. This PIN will allow the player to edit their profile on web
4. Leave blank if you don't want the player to have editing access

### Step 4: Save
- Click "Save" to store the player information including the PIN

### Step 5: Share the PIN
- Give the 4-digit PIN to the player privately
- Explain they can use it to edit their profile on the web version

---

## For Players: Editing Your Profile

### Step 1: Log into the Web App
- Open the TeamSync web app in your browser
- Navigate to your player profile

### Step 2: Start Editing
1. Look for the **pencil icon (✏️)** in the top-right corner
2. Click it to start the editing process

### Step 3: Enter Your PIN
1. A dialog will appear asking for your PIN
2. Enter the 4-digit PIN your coach gave you
3. Click "Unlock"

### Step 4: Edit Your Profile

#### Profile Picture
- Click "Upload Image" or "Change Image"
- Select a photo from your device
- The image uploads automatically on web
- Click "Remove Image" to delete

#### Action Photo
- Same process as profile picture
- This photo appears on player cards

#### Video Highlights
1. Click the **"+" button** in the Highlights section
2. Fill in:
   - **Title**: e.g., "Game-Winning Goal"
   - **Description**: Optional details
   - **Video URL**: Link to your video (YouTube, etc.)
   - **Date**: When it happened
3. Click "Add" to save
4. Edit or delete existing highlights using the icons

#### Awards/Recognitions
1. Click the **"+" button** in the Awards section
2. Fill in:
   - **Award Title**: e.g., "MVP", "All-Star", "Top Scorer"
   - **Description**: Optional details about the award
   - **Date**: When you received it
   - **Award Image**: Optional photo of trophy/certificate
3. Click "Add" to save
4. Edit or delete existing awards using the icons

### Step 5: Exit Edit Mode
- Click "Exit Edit Mode" button when you're done
- Your changes are saved automatically
- Your profile will return to normal view

## Troubleshooting

### "No PIN has been set for this player"
**Solution**: Ask your coach to set a PIN for you in the Players page

### "Incorrect PIN"
**Solution**: 
- Make sure you're entering the correct 4-digit number
- Ask your coach to verify or reset your PIN

### Can't find the edit button
**Solution**: 
- Make sure you're on the web version (not mobile app)
- The edit button (pencil icon) is in the top-right corner of your profile

### Images not uploading
**Solution**:
- Check your internet connection
- Try a smaller image file
- Make sure you're using a supported image format (JPG, PNG)

### Changes not saving
**Solution**:
- Check your internet connection
- Try refreshing the page and entering edit mode again
- Contact your coach if the problem persists

## Tips

✅ **DO:**
- Use clear, professional profile pictures
- Add meaningful video highlights
- Include awards you're proud of
- Keep descriptions concise
- Keep your PIN private

❌ **DON'T:**
- Share your PIN with others
- Upload inappropriate images
- Add false information
- Forget to exit edit mode when done
